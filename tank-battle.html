DUALING DRIVERS

2D 像素双人坦克对抗与关卡编辑器

2024.01 - 2024.05 5人团队 玩法策划 & 程序实现
Controller InputLevel EditorJSON 读写C# / Unity

01. GAME FEEL // 两套驾驶手感

手柄操控我用 C# 写了两套。街机模式是绝对方向映射——左摇杆往哪推，坦克往哪走，拿起来就能玩。拟真模式是左摇杆管左履带、右摇杆管右履带，像真的在开坦克：难上手，但操作上限高，硬核玩家玩得很爽。两套并存，休闲和硬核玩家各取所需。

02. LEVEL EDITOR // 让玩家自己造图

想让一个对抗原型活得久，就得让玩家自己造图。我做了个内置的网格地图编辑器：能摆陆地、水面（减速或不可通行）、可破坏的墙和不可破坏的墙；画好的地图序列化成 JSON 存到本地，主菜单里随时读回来开一局。

03. PROGRESSION // 官方关卡与选关

游戏自带几个官方关卡，每张图的地形和道具生成点（加速、修复、弹夹增幅）都单独调过。选关界面同时也是读取玩家自定义地图的入口——编辑器和选关打通之后，这个原型的图就永远打不完了。
